How the merge works

  • Nothing in the design changes. Every floor, detector, pipe run, sampling hole, end cap, T-piece, outline, label and saved PipeCAD result is copied exactly: coordinates, hole sizes, fan speeds, alarm settings, flows and transport times included.
  • IDs. PipeCAD numbers each file's detectors, pipes and holes from 0, and its saved results point at those numbers. Each later file's numbers are shifted by one fixed amount, together with every results reference, so nothing collides and every result still belongs to the same pipe or hole.
  • Names. Only names that clash with an earlier file change. Detectors continue their own numbering (MASD 01 → MASD 05, MASD 1-2 → MASD 1-7). Floors keep their description: Area A → Area B, Floor 1 → Floor 2, otherwise a copy number (Pipes 1 & 4 (2)). Pipe names belong to their detector and never clash. You can edit any new name before downloading.
  • Project settings (project details, units, pipe type, default options, snap grid) come from the first file. Files in different units, or with a different pipe bore or material, are refused because their airflow results would change. A different stick length or part number is allowed and flagged.
  • The file is written the way PipeCAD writes it: same XML declaration, indentation and Windows line endings.
