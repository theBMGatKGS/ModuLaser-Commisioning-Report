How the merge works

  • Every floor, with its detectors and pipe network, and every saved PipeCAD result is copied into one file.
  • IDs that clash with an earlier file are renumbered, and every reference to them in that file (for example the link from a detector to its saved results) is updated to match.
  • A floor or detector name already used in an earlier file gets the source file name added, e.g. MASD 1-2 (Level 2). The Field Report matches sheets by detector name, so names must be unique.
  • Files with different units are refused. Set them to the same units in PipeCAD and export again.
  • Project details and PipeCAD version differences are listed so you can see what was not carried over.
